# Chess Tournament Landing

Одностраничный сайт шахматного турнира, выполненный в рамках тестового задания.

## GitHub Pages
https://eirateufel.github.io/chess_club/

## Technologies

- HTML  
- CSS  
- JavaScript  

## Features

- Адаптивная верстка с использованием content-based breakpoints (брейкпоинты, основанные на контенте, а не на стандартных размерах устройств)  
- Анимация в хедере  
- Семантическая структура HTML  
- Кроссбраузерная верстка
